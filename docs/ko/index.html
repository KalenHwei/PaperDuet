Attention Is All You Need(15쪽)를 처음부터 번역하는 실제 화면

PaperDuet는 가벼운 AI 논문 미러 번역기입니다. 원문과 번역문을 거울처럼 나란히 놓고, 수식과 그림, 표를 페이지마다 바로잡아 맞춥니다. 무료로 쓸 수 있고, 로컬 모델을 쓰면 모든 작업이 내 컴퓨터에서 이뤄집니다. 원하면 온라인 API도 연결할 수 있습니다.

미러 레이아웃

어느 페이지든 한눈에

왼쪽에는 논문 원문, 오른쪽에는 번역문이 있고, 양쪽이 함께 스크롤되고 함께 확대·축소됩니다. 단, 제목, 캡션, 각주, 참고문헌을 자동으로 인식하고, 다음 단이나 페이지로 이어지는 문단도 하나로 이어 붙입니다. 양쪽이 정확히 맞춰져 있어 비교하기 쉽습니다.

저장과 요약

번역 저장? AI 요약? 문제없어요.

번역 진행 상황은 도구 막대에 표시됩니다. 논문 전체가 번역되면 링이 초록색 체크로 바뀌고, 클릭 한 번으로 번역문을 PDF로 원문 옆에 저장합니다. 옆의 전구를 열면 모델이 전체를 읽고 쓴 AI 요약이 나옵니다. 연구 질문, 방법, 결과가 한눈에 보입니다. 다섯 가지 모델 중 컴퓨터와 용도에 맞게 고를 수 있어요.

AI 정리와 검색

떠올리면, 찾아집니다.

읽은 논문은 모두 보관함에 모입니다. AI 정리가 분야, 세부 분야, 주제별로 태그를 달고, 고른 태그의 논문이 위로 떠오릅니다. AI 검색은 제목, 원문, 번역문, 요약까지 찾아 주며, 한국어로도 영어로도 검색할 수 있습니다.

더블클릭으로 먼저

모르겠다면? 클릭하세요.

먼저 제목들을 번역해 논문의 구조를 바로 보여 주고, 이어서 논문 제목, 초록, 서론을 번역합니다. 뒤쪽 문단을 먼저 보고 싶다면 원문을 더블클릭하세요. 진행을 기다릴 필요 없이 그 부분을 먼저 번역합니다.

번역문에 메모

메모요? 바로 됩니다.

번역문 위에 바로 하이라이트, 밑줄, 메모를 남기세요. 원문의 해당 문장에도 자동으로 같은 표시가 됩니다. 주석이 담긴 원문 PDF는 표준 PDF 주석으로 내보내므로 미리보기, Zotero 같은 앱에서도 그대로 보입니다.

이 밖에도

  • 10개 언어로 번역

    도구 막대에서 클릭 한 번으로 简体中文, 繁體中文, 日本語, 한국어, Français, Deutsch, Español, Italiano, Polski, Русский 사이를 전환할 수 있습니다.

  • 클릭 한 번으로 번역 PDF

    논문 전체 번역이 끝나면 클릭 한 번으로 원래 레이아웃 그대로 논문 옆에 저장합니다.

  • 품질 검사 내장

    모델이 답할 때마다 수식, 숫자, 문장 순서를 확인하고 문제가 있으면 자동으로 다시 시도합니다. 논문마다 용어집을 만들어 용어 번역도 일관되게 유지합니다.

  • 번역할 부분은 내가 결정

    어떤 블록이든 오른쪽 클릭으로 번역할지, 원문 그대로 둘지 고를 수 있습니다.

  • 원하는 방식으로 읽기

    원문과 번역문을 한 번에 검색하고, 이중 언어 목차를 따라가고, 문단에 포인터를 올려 반대쪽 짝을 찾을 수 있습니다. 원문만, 번역문만, 또는 둘 다 볼 수 있고, PaperDuet가 읽던 위치를 기억합니다.

  • 논문 보관함과 AI 검색

    읽거나 가져온 논문은 사이드바의 보관함에 모입니다. AI 검색은 제목, 원문, 번역문, 요약으로 읽은 논문을 다시 찾아 주고, 검색어는 한국어도 영어도 됩니다. AI 정리는 분야와 주제별로 논문을 나눕니다.

  • 논문 요약

    전체 번역이 끝나면 전구를 누르세요. 번역 모델이 인터페이스 언어로 짧은 요약을 써서 논문과 함께 저장합니다.

  • 어디로든 내보내기

    주석을 단 원문 PDF, 번역 PDF, Markdown 노트를 내보낼 수 있고, 다른 앱에서도 열 수 있습니다.

  • 클릭 한 번으로 업데이트

    새 버전으로 쉽게 업데이트하고, 클릭 한 번으로 설치합니다.

  • 보기에도 좋게

    깔끔하고 아름다운 유리 질감 디자인에 라이트, 다크, 야간 읽기 모드를 지원합니다.

5가지 모델, 모두 내 컴퓨터에서

PaperDuet를 처음 열 때 모델을 고르고, 나중에 설정 › 모델 › 모델 변경에서 언제든 바꿀 수 있습니다. 모두 번역 전용 모델이며, 한 번 다운로드하면 완전히 오프라인으로 동작합니다.

  • Index-Translate-2B추천
    bilibili Index 팀 · 2.1 GB

    가장 뛰어난 만능형, PaperDuet의 검사와 용어집에 맞춰 조정됨

  • Hy-MT2-1.8B
    Tencent Hunyuan · 1.9 GB

    속도: 가장 빠르고 가벼움

  • LMT-60-4B
    NiuTrans · 4.7 GB

    원문에 충실한 번역

  • Hy-MT2-7B
    Tencent Hunyuan · 8.0 GB

    가장 자연스러운 번역, 메모리 16GB 이상 컴퓨터용

  • TranslateGemma-4B실험적
    Google · 4.1 GB

    Google의 번역 모델을 써 보고 싶을 때

추천 모델로는 15쪽 논문이 M5 Pro에서 약 2분, 설정 › 모델에서 "동시 번역 문단 수"를 2나 3으로 하면 약 1분 걸립니다. LM Studio, llama.cpp, Hugging Face로 이미 이 모델들을 받아 두셨나요? PaperDuet가 찾아서 그 자리에서 사용하므로 다시 다운로드할 필요가 없습니다.

컴퓨터 사양이 낮아 로컬 모델이 버겁다면, 모델 선택에서 'API 사용'을 누르고 내 API 키를 입력하세요. OpenAI, Claude, DeepSeek, Qwen, Kimi, GLM, Doubao 또는 OpenAI 호환 서비스라면 어디든 연결할 수 있습니다. 로컬 모델 목록은 자동으로 접히고, 번역, 요약, AI 정리, AI 검색이 모두 그 서비스를 통해 이뤄집니다. API 키는 내 컴퓨터에만 저장됩니다.

처음부터 프라이버시 중심

  • 논문, 번역문, 메모는 모두 내 컴퓨터에 남습니다. API를 사용할 때는 번역할 텍스트가 선택한 서비스로 전송됩니다.
  • 동의한 경우에만 익명 사용 및 진단 데이터(버전, 시스템, 인터페이스 언어, 사용 모델, 오류 종류)를 보내며, 논문 내용은 포함하지 않고 설정에서 언제든지 끌 수 있습니다.
  • 오류가 생기면 개발자에게 오류 정보(무슨 오류인지, 버전, 시스템)를 보냅니다. 파일 경로와 논문 내용은 포함하지 않으며 ‘설정 › 데이터’에서 끌 수 있습니다.
  • 앱에서 피드백을 쓰고 ‘보내기’를 누르면, 쓴 내용(입력한 경우 이메일도)이 버전, 시스템 정보와 함께 개발자에게 전송됩니다.
  • 로컬 모델을 쓸 때는 인터넷에 모델을 다운로드하고, 업데이트를 확인하고, 위의 데이터와 오류 정보를 보내고, 피드백을 보낼 때만 연결하며, 모델 다운로드를 제외하고 모두 끌 수 있습니다.

시작하기

Mac은 Apple 실리콘(M1 이상)과 macOS 13.3 이상, Windows는 Windows 10 또는 11(64비트)이 필요합니다.

Mac

  1. 1

    Releases에서 최신 .dmg를 다운로드합니다.

  2. 2

    PaperDuet를 응용 프로그램 폴더로 드래그한 뒤 거기서 엽니다.

  3. 3

    처음 한 번만: PaperDuet는 아직 Apple의 공증을 받지 않아서 macOS가 확인을 요청합니다. 시스템 설정 › 개인정보 보호 및 보안을 열고 그래도 열기를 클릭하세요. (터미널에서 xattr -dr com.apple.quarantine /Applications/PaperDuet.app를 실행해도 됩니다.)

  4. 4

    모델을 고릅니다. PaperDuet가 모델을 다운로드하거나 이미 있는 사본을 찾아 바로 번역을 시작합니다.

Windows

  1. 1

    Releases에서 최신 Windows 설치 프로그램(_x64-setup.exe)을 다운로드합니다.

  2. 2

    설치 프로그램을 실행합니다. 처음 한 번만: 'Windows의 PC 보호' 창이 뜨면 추가 정보를 누른 뒤 실행을 누릅니다.

  3. 3

    모델을 고릅니다. PaperDuet가 모델을 다운로드하거나 이미 있는 사본을 찾아 바로 번역을 시작합니다.

이게 전부입니다. 번역 엔진은 앱에 내장되어 있고, 업데이트도 클릭 한 번이면 됩니다.

자주 묻는 질문

어떤 모델을 골라야 하나요?

Index-Translate-2B로 시작하세요. 더 빠른 속도를 원하면 Hy-MT2-1.8B, 메모리 16GB 이상 컴퓨터에서 가장 자연스러운 번역을 원하면 Hy-MT2-7B를 고르세요. 컴퓨터가 버거워하면 'API 사용'을 고르세요.
