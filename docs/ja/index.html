開けば、もう日本語

PaperDuet は論文の管理・学習・理解のためのツールです。原文と訳文を鏡のように並べ、数式・図・表もページごとに位置をそろえます。読んだ論文は本棚とナレッジスペースに集まり、AI でいつでも探し出せます。無料で使え、ローカルモデルならすべてパソコンの中で動きます。必要ならオンラインの API にもつなげます。

ナレッジスペース

あなたの論文ライブラリは、あなたの星空

Space の登場です。あなたの論文が、星空のように目の前に広がります。自分だけの「見える」知識ベースを、もっと直感的に作れます。

本棚と読書時間

ひとつひとつの進歩を記録

ホームの本棚は、何本読んだか、合計でどれだけ読んだか、何日続けて学んでいるかを記録します。マスひとつが 1 週間で、長く読んだ週ほど濃くなります。分野をクリックすると、下の論文とタイムラインも絞り込まれます。右クリックで自分のラベルも付けられます。

AI 検索

論文が見つからない？AI に聞こう！

タイトルを覚えていなくても大丈夫。探している内容をひとこと書けば、AI 検索がタイトル・原文・訳文・要約の中から見つけ出し、該当箇所も示します。日本語でも英語でも聞けます。

ミラーレイアウト

どのページも、そのままに

左に原文、右に訳文。両側は一緒にスクロールし、一緒に拡大縮小します。段組み、見出し、キャプション、脚注、参考文献は自動で認識し、数式・図・表も元の位置のまま。段落にポインタを合わせると、反対側の対応する段落が光ります。訳文の言語を切り替えても、レイアウトは変わりません。

訳文にメモ

メモを取りたい？おまかせ！

訳文に直接ハイライト、下線、メモ。原文の対応する文にも自動で同じ印が付きます。注釈付きの原文 PDF は標準の PDF 注釈で書き出すので、プレビューや Zotero などのアプリでもそのまま見られます。

保存と要約

読み終えたら、持ち帰る。

全文を訳し終えると、ツールバーのリングが緑のチェックに変わります。クリックひとつで、訳文 PDF、Markdown、注釈付きの原文がこの論文のフォルダにまとめて保存されます。隣の電球は AI 要約。モデルが全文を読んで書いたまとめで、研究の問い、手法、結果がひと目でわかります。

ほかにもいろいろ

  • 10 の言語に翻訳

    ツールバーで简体中文、繁體中文、日本語、한국어、Français、Deutsch、Español、Italiano、Polski、Русскийをワンクリックで切り替えられます。

  • ダブルクリックで先に訳す

    先に読みたい段落があれば、原文をダブルクリックするだけ。進捗を待たずに、そこから先に訳します。

  • 品質チェックを内蔵

    モデルの返答ごとに数式、数値、文の順番を確かめ、問題があれば自動でやり直します。論文ごとの用語集で訳語もそろえます。

  • 何を訳すかはあなた次第

    どのブロックも右クリックで、翻訳するか原文のまま残すかを選べます。

  • 好きなように読める

    原文と訳文をまとめて検索し、2 か国語の目次をたどり、段落にポインタを合わせれば反対側の対応箇所がわかります。原文だけ、訳文だけ、両方の表示を切り替えられ、読んでいた場所も覚えています。

  • 用語を自分で決める

    専門用語の訳し方を指定すれば、論文全体がそのとおりに訳されます。

  • スキャンも読める

    本文が文字ではなく図形として描かれた PDF は、Mac と Windows ではシステムの文字認識で読み取ってから翻訳します。

  • フォルダの自動更新

    フォルダを一度読み込めば、あとから入れた論文も自動でライブラリに並びます。

  • ワンクリックで更新、ワンクリックで掃除

    新しいバージョンはクリック 1 回でインストール。キャッシュも設定からクリック 1 回で消せます。

  • 見た目にもこだわり

    すっきりしたすりガラスのデザインで、ライト、ダーク、夜間読書の各モードに対応しています。

6 つのモデルが、すべてパソコンの中に

PaperDuet を初めて開くときにモデルを選び、あとから「設定 › モデル › モデルを変更」でいつでも切り替えられます。どれも翻訳専用のモデルで、ダウンロードが済めば完全にオフラインで動きます。

  • Index-Translate-2Bおすすめ
    bilibili Index チーム · 2.1 GB

    総合力がいちばん高く、PaperDuet のチェックと用語集に合わせて調整済み

  • Hy-MT2-1.8B
    Tencent Hunyuan · 1.9 GB

    速くて軽い

  • LMT-60-4B
    NiuTrans · 4.7 GB

    原文に忠実な訳

  • LMT-60-0.6B
    NiuTrans · 0.8 GB

    性能が控えめなパソコン：いちばん小さく、いちばん速い

  • Hy-MT2-7B
    Tencent Hunyuan · 8.0 GB

    いちばん流暢な訳文。メモリ 16 GB 以上のパソコン向け

  • TranslateGemma-4B試験的
    Google · 4.1 GB

    Google の翻訳モデルを試したいときに

おすすめのモデルなら、15 ページの論文が M5 Pro で約 2 分。「設定 › モデル」で「同時に翻訳する段落数」を 2 か 3 にすれば約 1 分です。 LM Studio、llama.cpp、Hugging Face でこれらのモデルをすでにダウンロード済みですか？ PaperDuet が見つけてそのまま使うので、もう一度ダウンロードする必要はありません。

パソコンの性能が足りずローカルモデルが重いときは、モデル選択で「API を使う」を選び、自分の API キーを入れてください。OpenAI、Claude、DeepSeek、Qwen、Kimi、GLM、Doubao、または OpenAI 互換の任意のサービスにつなげられます。ローカルモデルの一覧は自動で折りたたまれ、翻訳、要約、AI 整理、AI 検索はすべてそのサービスで動きます。API キーはパソコンの中にだけ保存されます。

プライバシーを最初から大切に

  • 論文、訳文、メモはすべてパソコンの中にとどまります。API を使う場合は、翻訳するテキストが選んだサービスに送られます。
  • 同意した場合に限り、匿名の使用状況と診断データ（バージョン、システム、表示言語、使用モデル、エラーの種類）を送信します。論文の内容は含まず、設定でいつでもオフにできます。
  • エラーが起きたときは、開発者にエラー情報（何が起きたか、バージョン、システム）を送ります。ファイルのパスや論文の内容は含まず、「設定 › データ」でオフにできます。
  • アプリでフィードバックを書いて「送信」を押したときは、書いた内容（入力した場合はメールアドレスも）がバージョンとシステムの情報とともに開発者に送られます。
  • ローカルモデルを使う場合、インターネットに接続するのは、モデルのダウンロード、アップデートの確認、上のデータとエラー情報の送信、フィードバックの送信のときだけです。モデルのダウンロード以外はオフにできます。

はじめかた

Mac は Apple シリコン（M1 以降）と macOS 13.3 以降、Windows は Windows 10 または 11（64 ビット）、Linux は 64 ビット版の Ubuntu 22.04 以降（または同程度に新しいディストリビューション）が必要です。

Mac

  1. 1

    Releases から最新の .dmg をダウンロードします。

  2. 2

    PaperDuet を「アプリケーション」フォルダにドラッグし、そこから開きます。

  3. 3

    初回のみ：PaperDuet はまだ Apple の公証を受けていないため、macOS が確認を求めます。システム設定 › プライバシーとセキュリティ を開き、このまま開く をクリックしてください。（ターミナルで xattr -dr com.apple.quarantine /Applications/PaperDuet.app を実行しても構いません。）

  4. 4

    モデルを選びます。PaperDuet がダウンロードするか、手元にあるものを見つけて、すぐに翻訳を始めます。

Windows

  1. 1

    Releases から最新の Windows 用インストーラー（_x64-setup.exe）をダウンロードします。

  2. 2

    インストーラーを実行します。初回のみ：「Windows によって PC が保護されました」と表示されたら、詳細情報 をクリックし、実行 をクリックします。

  3. 3

    モデルを選びます。PaperDuet がダウンロードするか、手元にあるものを見つけて、すぐに翻訳を始めます。

Linux

  1. 1

    Releases から最新の .deb（Ubuntu、Debian）か .AppImage（その他のディストリビューション、または管理者権限がない場合）をダウンロードします。

  2. 2

    .deb はターミナルで sudo apt install ./PaperDuet_*_amd64.deb を実行し、アプリケーションメニューから開きます。.AppImage はインストール不要で、chmod +x PaperDuet_*_amd64.AppImage を実行してからそのまま開きます。

  3. 3

    モデルを選びます。PaperDuet がダウンロードするか、手元にあるものを見つけて、すぐに翻訳を始めます。

これだけです。翻訳エンジンはアプリに組み込まれていて、アップデートもクリック 1 回です。

よくある質問

どのモデルを選べばいいですか？

まずは Index-Translate-2B から。速さを求めるなら Hy-MT2-1.8B、メモリ 16 GB 以上のパソコンでいちばん流暢な訳文が欲しいなら Hy-MT2-7B を選んでください。パソコンで動かすのが重い場合は「API を使う」を選んでください。
