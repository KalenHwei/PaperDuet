從頭翻譯 Attention Is All You Need（15 頁）的實際錄影

PaperDuet 是一款輕量的 AI 論文鏡像翻譯器。它把原文和譯文像鏡子一樣並排擺放，公式、圖片、表格逐頁修正、對齊。不用註冊、不用 API 金鑰、不用付費，全部在你的 Mac 上執行！

鏡像排版

每一頁都輕鬆對照

左邊是論文原文，右邊是譯文，兩邊一起捲動、一起縮放。分欄、標題、圖說、註腳和參考文獻都會自動辨識，跨欄、跨頁的段落也會自動接起來。左右完全對齊，對照起來很輕鬆。

雙擊插隊

快！快！快！

先翻各級標題，馬上看出論文的架構；接著是標題、摘要和引言，很快就能掌握重點。想先看後面的章節？在原文段落上點兩下，立刻開始翻！

兩邊同步標註

要做筆記？直接在譯文上做！

在任一邊畫重點、加底線或寫筆記，另一邊對應的句子也會一起標記。

譯完即存

進度？速度？沒問題！

工具列會顯示翻譯進度。整篇翻完後，圓環變成綠色勾號並跳出提示：點一下就能把譯文存成 PDF，放在原文旁邊。另外有五種模型可選，依你的 Mac 和需求自由搭配！

還有這些

  • 八種譯文語言

    在工具列一鍵切換简体中文、繁體中文、日本語、한국어、Français、Deutsch、Español、Русский。

  • 一鍵儲存譯文 PDF

    整篇翻完後點一下，就會依原始版面存到論文旁邊。

  • 內建品質檢查

    每次回覆都會核對公式、數字和句子順序，出錯自動重試；每篇論文自動整理術語表，讓譯法前後一致。

  • 翻譯什麼由你決定

    在任一區塊按右鍵，選擇翻譯它或保留原文。

  • 想怎麼讀都順手

    原文和譯文同時搜尋、雙語目錄、指標移到段落上就能找到另一邊對應的段落，可以只看原文、只看譯文或兩邊都看。PaperDuet 支援「上次讀到」功能。

  • 匯出到任何地方

    帶標註的原文 PDF、譯文 PDF、Markdown 筆記，換到其他 App 也能看。

  • 一鍵更新

    新版本更新方便，一鍵安裝。

  • 為美感而生

    簡潔漂亮的毛玻璃設計，支援淺色、深色和夜間閱讀模式。

五種模型，全在你的 Mac 上

第一次打開 PaperDuet 時選一個模型，之後隨時可以在「設定 › 模型 › 更換模型」裡更換。五種都是翻譯專用模型，下載後完全離線執行。

  • Index-Translate-2B推薦
    嗶哩嗶哩 Index 團隊 · 2.1 GB

    綜合表現最好，PaperDuet 的檢查和術語表專門為它調整過

  • Hy-MT2-1.8B
    騰訊混元 · 1.9 GB

    追求速度：最快也最輕

  • LMT-60-4B
    小牛翻譯 NiuTrans · 4.7 GB

    貼近原文的譯法

  • Hy-MT2-7B
    騰訊混元 · 8.0 GB

    譯文最通順，適合 16 GB 以上記憶體的 Mac

  • TranslateGemma-4B實驗性
    Google · 4.1 GB

    想試試 Google 的翻譯模型

用推薦的模型，15 頁的論文在 M5 Pro 上大約 2 分鐘翻完；在「設定 › 模型」把「同時翻譯幾段」調成 2 或 3，大約 1 分鐘。 已經用 LM Studio、llama.cpp 或 Hugging Face 下載過這些模型？PaperDuet 會自動找到並直接使用，不必重新下載。

隱私為先

  • 論文、譯文和筆記都留在你的 Mac 上。
  • 不需要帳號，也不收集使用資料。
  • 只有下載模型和檢查更新時才會連網，檢查更新也可以關掉。

開始使用

需要搭載 Apple 晶片（M1 以後）的 Mac，以及 macOS 13.3 以上。

  1. 1

    從 Releases 下載最新的 .dmg。

  2. 2

    把 PaperDuet 拖進「應用程式」，從那裡打開。

  3. 3

    僅限第一次：PaperDuet 還沒有通過 Apple 公證，macOS 會請你確認。打開「系統設定 › 隱私權與安全性」，按下 強制打開。（也可以在終端機執行 xattr -dr com.apple.quarantine /Applications/PaperDuet.app。）

  4. 4

    選一個模型。PaperDuet 會下載它，或找到你已有的那份，然後馬上開始翻譯。

就這麼簡單。翻譯引擎已經內建在 App 裡，更新也只要點一下。

常見問題

該選哪個模型？

先用 Index-Translate-2B。想要更快，選 Hy-MT2-1.8B；想要最通順的譯文，而且 Mac 有 16 GB 以上記憶體，選 Hy-MT2-7B。
